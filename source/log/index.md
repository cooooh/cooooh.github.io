- 博客正式上线：基于 Hexo + Butterfly 搭建，开设「知识 / 项目 / 生活」三大栏目
- 上线功能：标签分类、全文搜索、暗色模式、字数统计
- 接入网易云歌单播放器（页面左下角悬浮，可展开歌单）
- 首页副标题改为静态展示：人生到处知何似，应似飞鸿踏雪泥
- 导航「关于」下新增「更新日志」弹窗（你现在看到的就是它）
- 播放器升级为独立音乐页：黑胶唱片随播放旋转发光，封面跟随歌曲切换
- 「关于」页新增「个人设置」卡片：可在站内直接更换头像和首页背景（保存在本机浏览器）
- 绑定自定义域名 snowtrace.top，全站 HTTPS
- 新增「写文章」页：网页内编写并发布文章（通过 GitHub API 提交，自动部署上线）
- 「写文章」定为单用户模式：仅站点作者通过一次性发布密钥发文，无需登录系统
- 「关于我」页改版为「个人设置」页：站内更换头像、个人简介、首页背景
- 导航新增「生活」分组：番剧、小说两个资源分区（卡片式资源列表，支持封面/标签/网盘磁力链接与搜索）
- 「写文章」支持多级分类（如「生活,番剧」），分类候选补充番剧/小说
- 导航「分类」改为下拉（知识/项目/生活），「生活」悬停二级展开番剧/小说；移除独立「生活」菜单
- 分类页新增「在本分类写文章」入口（自动预填分类）；番剧/小说页新增独立「添加资源」页（写数据文件并自动部署）
- 修复图标显示为 ×：图标库从 Font Awesome 7.x 锁定回 6.5.2 并自托管
- 导航精简：移除「标签」「写文章」菜单项，删除标签页（文章标签仍可在文章页看到）
- 上线删除管理：保存过发布密钥的浏览器可在首页/归档/分类/文章页删除文章，在番剧/小说页删除资源
